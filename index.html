LLM Server Controller

Полнофункциональное настольное приложение для удобного запуска и управления локальным сервером llama-server, интерактивным llama-cli, бенчмарками, менеджером моделей и поиском по HuggingFace.

Основные возможности v0.2.1

💬 Интерактивный llama-cli

Запуск чата прямо во встроенном терминале без поднятия сервера, раздельные группы параметров для промптов и генерации, предпросмотр команды.

📊 Продвинутый llama-bench

Пакетные тесты производительности с поддержкой списков значений через запятую, экспорт результатов в .txt и история последних замеров.

🤗 Менеджер моделей & HuggingFace

Удобный просмотр локальных .gguf моделей, встроенный поиск по HuggingFace Hub с сортировкой, отслеживанием прогресса и скачиванием в один клик.

💻 Встроенный Терминал

Настоящая системная консоль прямо в правой панели (cmd.exe в Windows, xterm в Linux) для интерактивных утилит.

⚙️ 18 категорий настроек

Расширенная гибкая конфигурация: контекст, GPU, память, CPU, batch, параметры генерации, MoE, Embeddings/Reranking, SSL и опции бэкендов.

🌙 Темы и Локализация

Поддержка тёмной и светлой темы оформления, а также мгновенное переключение языка интерфейса (RU / EN).

Быстрый запуск

Шаг 1

Запустите контроллер и скачайте бэкенд через Файл → Установить llama.cpp.

Шаг 2

Скачайте модель в Файл → Модели… через HuggingFace или выберите локальный .gguf.

Шаг 3

Настройте GPU-слои, контекст и параметры генерации в боковом меню.

Шаг 4

Нажмите Старт для сервера или запустите интерактивный чат через llama-cli!

Системные требования

  • ✔ Windows: Windows 10/11 x64 (полная поддержка).
  • ✔ Linux: Ubuntu 20.04+ (пакеты .deb, .rpm, .tar.gz).
  • ✔ Python: Версии 3.8–3.12 (при сборке из исходных файлов).
