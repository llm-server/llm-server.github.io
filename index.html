LLM Server Controller

Полнофункциональное настольное приложение для удобного запуска и управления локальным сервером llama-server, с встроенным терминалом, менеджером моделей и поиском по HuggingFace.

Основные возможности v0.2.0

🤗 Менеджер моделей & HuggingFace

Удобный просмотр локальных .gguf моделей, встроенный поиск по HuggingFace Hub с сортировкой, отслеживанием прогресса и скачиванием в один клик.

💻 Встроенный Терминал

Настоящая системная консоль прямо в правой панели (cmd.exe в Windows, xterm в Linux). Поддерживает интерактивные TUI-утилиты (например, pi).

🕹️ Статус-контроллер & Версия

Индикатор статуса с цветовой индикацией (зеленый/оранжевый/синий) и живое определение установленной версии llama-server через опрос --version.

⚡ Установка pi-агента

Быстрый запуск установки консольного pi-агента прямо из меню приложений (Файл → Установить pi-агента).

⚙️ 18 категорий настроек

Расширенная гибкая конфигурация: контекст, GPU, память, CPU, batch, параметры генерации, MoE, Embeddings/Reranking, SSL и опции бэкендов.

🌙 Темы и Локализация

Поддержка тёмной и светлой темы оформления, а также мгновенное переключение языка интерфейса (RU / EN).

Быстрый запуск

Шаг 1

Запустите контроллер и скачайте бэкенд через Файл → Установить llama.cpp.

Шаг 2

Скачайте модель в Файл → Модели… через HuggingFace или выберите локальный .gguf.

Шаг 3

Настройте GPU-слои, контекст и параметры генерации в боковом меню.

Шаг 4

Нажмите Старт. Сервер запустится на порту 18080 и откроется в браузере!

Системные требования

  • ✔ Windows: Windows 10/11 x64 (полная поддержка).
  • ✔ Linux: Ubuntu 20.04+ (пакеты .deb, .rpm, .tar.gz).
  • ✔ Python: Версии 3.8–3.12 (при сборке из исходных файлов).
